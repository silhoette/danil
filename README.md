# Симуляция броска тела под углом к горизонту (Unity)

Небольшая учебная симуляция в Unity, показывающая, как сопротивление воздуха
меняет траекторию тела, брошенного под углом к горизонту.

## Физическое явление
Тело, брошенное со скоростью `v0` под углом `α`, движется под действием силы тяжести.
- **В вакууме** траектория - парабола, дальность `L = v0² · sin(2α) / g`.
- **С воздухом** добавляется сила сопротивления, пропорциональная квадрату скорости:
  `a = g − k·|v|·v`. Траектория становится несимметричной, дальность и высота уменьшаются.

## Что показывает проект
- 🔴 красный шар - полёт без сопротивления воздуха;
- 🔵 синий шар - полёт с сопротивлением;
- за шарами остаются следы траекторий;
- слайдерами меняются скорость, угол, коэффициент сопротивления `k` и ускорение свободного падения `g`;
- выводятся дальность и максимальная высота для обоих случаев.

Если поставить `k = 0`, траектории совпадут. Если поставить `g = 1.6` (Луна), тело улетит гораздо дальше.

## Как запустить
1. Версия Unity: 2021.3 LTS или новее (подойдёт любая 3D-шаблонная).
2. Склонировать репозиторий и открыть папку через **Unity Hub → Add**
   (либо создать новый 3D-проект и скопировать `Assets/Scripts/ProjectileSimulation.cs`).
3. Открыть любую пустую сцену, создать пустой объект (`GameObject → Create Empty`)
   и перетащить на него скрипт `ProjectileSimulation`.
4. Нажать **Play**.

## Управление
Слайдеры в левом верхнем углу, кнопка **«Запуск / Перезапуск»** запускает бросок заново.

## Реализация
Весь код - в `Assets/Scripts/ProjectileSimulation.cs`. Движение считается численно
(полунеявный метод Эйлера в `FixedUpdate`), траектории рисуются `LineRenderer`,
интерфейс сделан через `OnGUI`. Все объекты сцены создаются из кода.
